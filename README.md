# Denuncias RS - Extension

Auto-llenado de formularios de denuncia (Facebook, Instagram, WhatsApp, LinkedIn, X, TikTok, Telegram, YouTube).

## Instalar (una vez por PC)
1. Descarga **DENUNCIAS_RS.bat**.
2. Ponlo en una carpeta (ej. Escritorio) y dale **doble clic**.
3. Aparece la carpeta **DenunciasRS_extension** al lado del .bat.
4. En `chrome://extensions` -> Modo de desarrollador -> "Cargar descomprimida" -> elige **DenunciasRS_extension**.

## Se actualiza SOLA
Al instalar, queda una tarea programada que baja la ultima version automaticamente
(al encender la PC y a diario). Solo reinicia Chrome de vez en cuando para aplicar lo nuevo.
No muevas ni borres el .bat ni su carpeta.

Este repo solo contiene la extension distribuible; el codigo de desarrollo esta en un repo privado.
